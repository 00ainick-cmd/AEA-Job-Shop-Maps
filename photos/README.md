# Shop photos

Each shop gets its own folder here, named after the shop (for example `photos/spencer-avionics/`).
List the files in the `photos` column of the member spreadsheet, separated by semicolons:

    photos/spencer-avionics/hangar.jpg; photos/spencer-avionics/bench.jpg

Keep photos under about 400 KB each and roughly 1200 pixels wide so profiles load quickly.
The `sample/` folder holds drawn placeholders used by the sample profile. They are not photographs of a real shop.
